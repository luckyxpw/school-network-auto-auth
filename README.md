# 校园网自动认证

Windows 11 校园网后台自动认证工具。

## 使用方法

1. 连接校园网 Wi-Fi。
2. 运行 `校园网自动认证.exe`。
3. 填写账号、密码和经过确认的 Portal 登录页。
4. 点击“识别表单”。
5. 点击“测试登录”。
6. 成功后点击“保存并启用”。

首次运行不预置任何学校或运营商模板。

完整说明见压缩包中的 `使用说明.md`，或 GitHub 仓库的 `docs/使用说明.md`。

## 系统要求

- Windows 10/11
- 可访问的校园网账号
- 普通 HTML 用户名密码认证页面

复杂验证码、CAS、OAuth、SAML、MFA 和前端密码加密暂不支持。
